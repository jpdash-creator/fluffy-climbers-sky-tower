# Gameplay (Meta scene UI) notes

## First-time help (owner 2026-11-25)

- **Text:** one static table, `HelpTable.cs` (topic id, pages, rows of icon spec + text). Icon specs: plain name = `Resources/Art/Ui/<name>`, `rw:` Art/Rewards, `pw:` Art/PowerUps, `ch:` Art/Chests, `g:` code glyph on a blue plate, `gp:<0..4>` Gameplay setting icon. Topic ids are permanent (they are stored in the save).
- **Rules (no UI):** `Economy/HelpProgress.cs` (list logic + `ProgressService.IsHelpSeen/MarkHelpSeen/ResetHelpSeen`, quiet saves), `HelpState.cs` (switch + marks: `ShouldShow`, `Unseen`, `MarkSeen` turns the switch off when every topic is seen, `ShowAgain`).
- **Save:** `SaveData.HelpSeen` (`helpSeen`), `SyncedSettings.Help` (`help`, default OFF, in `GameSettings.Snapshot/ApplyFromSave`), `GameSettings.Help` (PlayerPrefs mirror). Reset progress keeps the marks. No policy change (no new data leaves the phone beyond the existing cloud save file).
- **Popup:** `HelpPopup.cs` (carousel: swipe, dots, Back/Next, "Got it" on the last page, X, back key; vertical drag when a page is taller than the room; Reduced motion snaps pages). Painted frame: `HelpFrameArt` / `Resources/Art/Ui/help_frame_tall` (1616 x 2116, built from the old 1616 x 1698 frame by `Tools/art_pipeline/make_help_frame_tall.py`: two rope periods inserted, nothing stretched; a short page is centred between the ribbon and the button row with extra row gaps, `MaxExtraRowGap`) + `help_ribbon` (one uniform-scale picture, content inside its cream rect, sized from the REAL safe rect, never wider than safe width minus margins; without either file the code card is the frame). One bottom row: Back, page dots (indicator only, no touch targets), Next or Got it. Pages of at most 4 short rows; a page may scroll (chevron shown) because the cream area is small.
- **Host:** `MetaController.Help.cs`. `UpdateHelp()` (called from `Update`, polls 4x a second) notices a screen or tab change (`CurrentScreen` plus Shop tab / Rewards tab), waits 0.4 s, and shows the unseen topics of that screen as ONE carousel when nothing else is open (no `popup`, no other canvas child). `NewScreen` calls `CloseHelp()`. The three `LoadScene("Run")` calls of the Meta scene go through `LoadRunScene()`, which shows the Gameplay help first when due. Settings row: Help switch + "Show help again" (`AddSettingsHelpRow`).
- **Not covered on purpose:** Home (two buttons), the pop-ups (level, Endless, crown, hero reveal, consent): their icons are explained on the Level screen and Hero sheet topics.
- **Tests:** `Tests/EditMode/HelpTests.cs` (marks, auto-off, show again, save fields, table), `Tests/PlayMode/HelpUxTests.cs` (layout on every aspect, notch, 100 and 130 percent text).
